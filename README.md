# 미국주식 차트분석기

102개 미국 종목(대형주 100 + NKE, QQQ)의 최근 1,505 일봉(2020-11-30~2026-11-25)을 한 화면에서 보는 단일 HTML 차트 분석 도구입니다.
이 중 **앞쪽 250봉은 지표 워밍업**, 뒤쪽 **1,255거래일(2021-11-26~2026-11-25, 정확히 5년)** 이 추세형·스윙형 백테스트 구간입니다 — 2022년 하락장이 포함됩니다.
거시 지표(VIX · 미 10년물 금리), **CNN 공포·탐욕 지수(Fear & Greed) 반원 게이지와 상황별 심리 해석**, 종목별 펀더멘털(Forward/Trailing PER, 매출성장률, 애널리스트 목표가, 배당수익률, 52주 범위)을 함께 보여줍니다.
엘리엇 파동 심층분석, 작도 도구, 일목균형표, 이동평균, 거래량 분석을 포함합니다.
W 쌍바닥(이중 바닥)은 차트에 L1 → 넥라인 → L2 → 돌파 W자 선과 라벨로 표시되고(토글 · 기본 ON, 브라우저에 저장),
스캐너 프리셋 `W 쌍바닥`으로 마지막 종가 기준 돌파·임박·진행 종목만 추려 볼 수 있으며,
스캐너의 상단 탭(전체 · 매수 신호 · 매도 신호 · 관심)과 6개 프리셋(시총 Top 30 · 실적 우량주 · W 쌍바닥 · VCP · 삼각수렴 · 다이버전스)은 서로 독립이라
프리셋 하나를 켠 채 매수/매도/관심 탭을 눌러 **교집합**으로 좁힐 수 있습니다(같은 프리셋을 다시 누르면 해제).
스윙형 전략에는 `QQQ > 200일선`에서 W 넥라인 상향 돌파를 받는 보조 진입 루트가 들어 있고(99종목 5년 평균 +104.99%),
진입은 `RSI(2) < 10`이며 **손절로 끝난 종목은 10거래일 동안 신규 진입을 금지**합니다(패배 956 → 732건, 평균 MDD -36.40 → -33.73%).
청산은 이익 +5% 이상에서 종가가 20일선 아래로 **2거래일 연속** 마감해야 발동합니다(하루 이탈은 넘김).
추세형은 QQQ 위험 0%의 전량 청산을 **진입 3거래일 이후**에만 발동해 1~2일 왕복 매매를 없앴습니다(손절 6 ATR·트레일 10 ATR은 즉시).

### 화면·사용성 (2026-11-27 개선)

- **상승 다이버전스(RSI14) 참고 배지** — 10일 신저가인데 RSI(14)가 5~60봉 전 직전 저점보다 높은 자리(최근 3거래일 기준)를 스캐너 행 `다이버전스` 배지·프리셋 필터·상단 카드·차트 점선(라벨 `다이버전스`)으로 표시합니다. 과거 99종목 5년 검증에서 같은 RSI 매수 자리 중 다이버전스가 있던 곳이 20일 뒤 +3.30% vs +1.62%(t=4.35)였지만, **진입 규칙에는 넣지 않는 표시 전용**입니다(필터로 쓰면 거래가 줄어 총수익이 붕괴). `깔끔 보기`에서 함께 숨습니다.
- **스캐너 신호 = 전략 상태** — 행의 신호 칸은 기술점수 라벨(차트 강세/차트 양호/차트 중립/차트 약세/차트 극약세) 대신 상단 카드와 같은 `trendStatus`/`swingStatus` 판정만 씁니다. `진입 · 보유 · 대기 · 시장대기 · 손절대기 · 청산` 중 하나로 표시되고 매수/매도 탭도 같은 판정입니다. 활성 전략은 채운 칩, 반대 전략은 아래 줄 작은 글씨(`추세 보유`, `스윙 대기`)로 함께 보여 두 전략 상태를 한눈에 봅니다.
- **기간 양방향 동기화** — 위 차트 기간(`3M·6M·1Y·2Y·5Y`)과 아래 자료 기간이 같은 값을 씁니다. 어느 쪽을 눌러도 차트·KPI·자산곡선·전략 비교·트레이드 로그가 같은 기간으로 함께 바뀌고, 첫 화면은 6M입니다.
- **위쪽 여유 공간** — Y축 상단 패딩을 가격 범위의 15% 안팎으로 넉넉히 두어 고점 라벨·추세선이 차트 천장에 붙지 않습니다(아래쪽은 기존 비율).
- **기술점수 라벨 → 차트 상태 표현** (2026-11-27) — 0~100 종합 기술점수의 구간 이름을 매매 지시처럼 보이던 `강력매수 / 매수 / 관망 / 매도 / 강력매도`에서 `차트 강세(75+) / 차트 양호(58~74) / 차트 중립(45~57) / 차트 약세(35~44) / 차트 극약세(<35)`로 바꿨습니다. 실제 전략 신호(추세형·스윙형의 진입·청산·손절)와 모의매매 매수/매도 버튼은 그대로입니다. 상단 종목 카드의 기술점수 영역과 종합 기술점수 산출 근거 카드에 **`개별 차트 참고 점수 · 실제 진입은 전략 신호 기준`** 안내를 상시 표시해, `차트 강세`인데 `시장대기`인 조합이 왜 생기는지 바로 읽히게 했습니다. 102종목 백테스트 수치는 변경 전과 동일(diff 0).
- **시장대기 배지** — 시장 단계가 위험(추세형) 또는 QQQ 200일선 아래(스윙형)일 때 스캐너 행의 `제한` 배지를 `시장대기`로 바꿔, 매도가 아니라 **신규 매수 보류**라는 뜻을 바로 알 수 있게 했습니다(툴팁에 사유, 옆 숫자는 차트 참고 점수).
- **깔끔 보기** — 차트 툴바 맨 앞 토글(기본 OFF·브라우저 저장). 켜면 구름대·볼린저·엘리어트(피보나치/채널/패턴)·W 쌍바닥·삼각수렴·SAR 을 잠시 숨기고 **캔들 + 20·240일선 + 고저점**만 남깁니다. 끄면 기존 오버레이 구성 그대로 복귀.
- **라벨 겹침 해소** — 지지·목표·무효화·클러스터·최고/최저 라벨을 공통 배치 엔진(우선 자리 → 세로 밀어내기 → 패널 전체 탐색)으로 그려 서로 겹치지 않습니다.
- **데이터 갱신 시각** — 상단 `2026-11-25 장마감 · 11/27 10:56 갱신` 처럼 한국시간 갱신 시각을 병기하고(푸터에도 표시), 미국 휴장일에도 "오늘 확인을 마쳤다"를 바로 알 수 있습니다. `data.js` 의 `updatedAt`(KST)이며 `build.py` 가 `<meta name="apex-data-updated">` 로도 심습니다.
- **분석 종목 수·실적 임박 배지** — 사이드바 `분석 N종목` 은 데이터에서 동적으로 계산해 `전체 N` 과 항상 일치합니다. 실적 발표가 **D-0~D-3** 인 종목은 스캐너 행에 앰버 배지(`실적 D-2`)로 표시합니다.
- **백업·복원** — 가상투자(모의매매) 카드의 `백업 내보내기`/`복원하기`. `localStorage` 의 `apex.*`(가상투자 기록·관심종목·차트 작도·전략/토글 설정)를 `apex-quant-backup-YYYY-MM-DD.json` 하나로 내려받고, 검증 후 되돌립니다(백업에 담긴 항목만 덮어씀).
- **Y축 자유 이동·여백 조절** (2026-11-27) — 차트를 마우스·터치로 끌면 좌우(X)와 위아래(Y)가 함께 움직여, 아래로 끌면 위쪽에·위로 끌면 아래쪽에 빈 공간이 열립니다. 오른쪽 가격 눈금을 위아래로 끌면 세로 가격폭(배율)이 바뀌고(커서가 ↕), 차트나 축을 **더블클릭**하거나 기간(3M~5Y)·종목을 바꾸면 자동 맞춤(상단 15% 여백)으로 돌아갑니다. 이동 범위는 가격 범위의 ±150%, 배율은 0.35~4배로 제한해 캔들이 화면 밖으로 사라지지 않습니다. 커서를 올리면 가로 크로스헤어와 그 가격이 오른쪽 축에 표시됩니다.
- **PC 레이아웃·확대** — PC(폭 900px 초과)에서는 거래량·RSI·MACD 세로를 33% 줄여 메인 캔들 영역을 넓혔고(모바일은 기존 비율), 확대하면 **보이는 캔들 고저 기준으로 Y축을 다시 잡아** 캔들이 세로로 크게 확대됩니다(멀리 있는 이평선·목표/무효화 레벨은 축에서 제외).

## 자동 갱신

미국 증시 마감 후 매일 아침(KST) 최신 일봉으로 `scripts/data.js` 와 `index.html` 이 다시 만들어져 커밋됩니다.
갱신은 `scripts/update_data.py`(Yahoo Finance 10년 일봉을 받아 최근 1,505봉만 유지 + `^VIX`·`^TNX` + 펀더멘털 + CNN 공포·탐욕 지수 수집 → `data.js`) → `scripts/build.py`(`index.html` 재생성) 순서로 돌고,
GitHub Pages 가 `main` 브랜치를 그대로 배포하므로 커밋 후 몇 분 안에 사이트에 반영됩니다.

`data.js` 에는 `updatedAt`(데이터를 확인해 기록한 한국시간)이 함께 들어가고, 휴장일처럼 값이 그대로인 날에도 이 시각만 갱신해 다시 씁니다(NOCHANGE 로그) — 상단 배지가 "오늘 확인 완료"를 보여 주기 위해서입니다.

공포·탐욕 지수는 `window.MARKET.fearGreed`(현재 점수·등급·직전 마감·1주/1개월/1년 전·갱신 시각)로 `data.js` 에 들어갑니다.
페이지를 열면 이 값으로 즉시 그린 뒤, 브라우저에서 CNN API(`production.dataviz.cnn.io`)를 한 번 더 시도해 성공하면 `실시간`으로 바꿔 그립니다(4초 타임아웃, 실패·CORS 차단 시 조용히 `일일 갱신` 값 유지).
CNN API 가 일시에 실패해도 `update_data.py` 는 기존 `data.js` 의 `fearGreed` 를 그대로 이어 씁니다.

GitHub Actions 로 돌리고 싶다면 `docs/update-stocks.yml` 을 `.github/workflows/update-stocks.yml` 로 옮기면 됩니다
(화~토 21:30 UTC = 수~일 06:30 KST 자동 실행 + 수동 실행 버튼).

## 구조

```
index.html                  배포되는 단일 파일 앱 (scripts/ 조각들을 합친 결과물)
scripts/
  update_data.py            Yahoo Finance 10년 일봉 → 최근 1,505봉(5년+워밍업) + VIX·US10Y + 펀더멘털 → data.js 생성
  build.py                  template + data + engine + ui → index.html
  template.html  ui.css  engine.js  ui.js  data.js  top100.json
docs/update-stocks.yml      GitHub Actions 워크플로 템플릿
```

## 로컬에서 갱신하기

```bash
python scripts/update_data.py   # 인터넷 필요, 102종목 10년 일봉 → 최근 1,505봉 + 거시지표 + 펀더멘털 수집 후 data.js 갱신
python scripts/build.py         # index.html 재생성
```

`update_data.py` 는 일부 종목 수집에 실패하면 기존 `data.js` 를 그대로 두고 경고만 출력합니다(사이트는 이전 데이터로 정상 동작).
